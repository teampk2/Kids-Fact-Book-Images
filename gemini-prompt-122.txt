## Fact Box Color Theme Logic (Apply to All Fact Box Pages)

### Required Implementation

Apply the following color logic consistently across **all Fact Box pages** in the book (all 1,000 Fact Boxes).

### Unique Color Logic for Every Page

Each Fact Box on a page must have its **own unique solid color**.

#### Requirements

* Every Fact Box on the same page must use a **different solid color**.
* **No color may be repeated within the same page.**
* Each Fact Box must have a unique background color that is clearly distinguishable from the others.
* **The colors must be selected randomly for every page**, so the color arrangement changes from page to page.
* **Do not use the same color sequence or pattern on every page.**
* The position of each color should also be randomized, making every page look different and visually interesting.
* The color assignment should be fully automatic and applied consistently throughout the entire book.

---

## Color Palette Requirements

Use a high-quality collection of **solid colors only**.

#### Requirements

* Do **not** use gradients.
* Do **not** use vibrant or overly saturated colors.
* Do **not** use color blends.
* Do **not** use multi-color backgrounds.
* Do **not** use patterns or textures.
* **Never use white (#FFFFFF) or near-white colors as Fact Box background colors.**
* **Do not use any background color that makes the Fact Box appear white, off-white, ivory, cream, or extremely pale.**

Instead, use clean **light and medium-tone solid colors** that are:

* Soft and pleasant to look at
* Child-friendly
* Visually balanced
* Harmonious with the overall book design
* Comfortable for long reading
* Suitable for professional Amazon KDP printing

Each Fact Box should have a single solid background color that complements the overall page while remaining unique.

---

## Text Readability

Readability is the highest priority.

For every Fact Box:

* Automatically select the text color that provides the highest contrast against the background.
* Ensure all titles, fact text, icons, labels, numbers, and other content remain crisp, clear, and easy to read.
* Never allow text to blend into the background.
* Maintain excellent accessibility through strong contrast ratios.
* Preserve sharp text rendering with no blur, fading, or color bleeding.

---

## Automatic Contrast Logic

The rendering logic must automatically determine the most readable text color based on the background color of each Fact Box.

Examples:

* Light background → Dark text
* Medium-tone background → Automatically choose the text color that provides the highest readability
* If a darker color is used → White or very light text

This decision should be made independently for every Fact Box.

---

## Consistency

Apply this logic to **every Fact Box page** throughout the entire book.

Ensure:

* Every Fact Box on a page has a unique solid color.
* No duplicate colors appear on the same page.
* Colors are selected **randomly** for every page, creating a different color arrangement throughout the book.
* Avoid repeating the same color order or layout across multiple pages.
* Use **only solid light and medium-tone colors**, excluding white and near-white shades.
* Every Fact Box background should be colorful and clearly distinguishable.
* The color distribution is visually balanced.
* The design remains consistent across all pages.
* The final output is professional, engaging, print-ready, and fully optimized for Amazon KDP.

### Expected Result

The final result should be a visually appealing children's book in which every Fact Box has its own **randomly assigned light or medium-tone solid color**. Every page should have a fresh, different color arrangement, **white should never be used as a Fact Box background**, and all text should remain highly readable with excellent contrast for a clean, premium-quality, print-ready design.
