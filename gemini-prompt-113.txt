**Add 8.25 × 11 Inch Trim Size to the Simulate Trim Size Section**

In the **Kids Interesting Facts** web app, add a new **Simulate Trim Size** option: **8.25 × 11 inches**.

### Requirements

* Add **8.25 × 11 inches** as a selectable trim size alongside the existing options.
* When this trim size is selected, automatically apply all page layout settings according to the latest **Amazon KDP** print specifications.
* Generate the simulated book PDF using the correct:

  * Trim Size
  * Bleed
  * Safe Area
  * Inside (Gutter) Margin
  * Outside Margin
  * Top and Bottom Margins
  * Page Content Area
* Automatically scale and position all content, including fact cards, images, text, icons, page numbers, headers, footers, and other elements, so they fit perfectly within the selected **8.25 × 11 inch** trim size.
* Ensure no content is clipped, stretched, distorted, or placed outside the KDP safe area.
* Generate a **print-ready PDF at 300 DPI** that fully complies with the latest **Amazon KDP** printing requirements.
* The preview and the exported PDF must match exactly.
* Apply this implementation consistently to all current and future KDP book PDFs generated by the application.
