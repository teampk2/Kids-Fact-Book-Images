# Ultimate Amazing Fact Championship — Download Logic

From now on, add two download options in the web app for the **“ULTIMATE AMAZING FACT CHAMPIONSHIP”** content used in the PDF book:

**Download as Excel (.xlsx)**
**Download as TXT (.txt)**

Both files must contain the **exact same content and order** as the championship page in the PDF, including:

The **Excel file** should use clean columns and formatting that match the PDF structure as closely as practical.

The **TXT file** should preserve the same reading order and section structure.

Use the **same source dataset that generates the PDF page** for both exports. Do not rewrite, paraphrase, regenerate, or use old data.

Whenever a new Kids Facts Book is created, completely replace the previous championship data so the Excel and TXT downloads contain only the **current book’s** content.

Before enabling download, verify that both exports match the current championship page data exactly.
