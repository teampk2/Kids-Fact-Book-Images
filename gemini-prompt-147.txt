# Image Discovery Facts (31 Image Facts) — Prompt Export, Category Mapping & SVG Icon Logic

In the **“Image Discovery Facts (31 Image Facts)”** section, use the **Excel file uploaded by the user** as the source of truth for the 31 Grid Facts.

The application must correctly connect each Grid Fact with its image-generation prompt, metadata, category, and category-specific SVG icon.

## 1. 31 Grid Fact Data Source

For each of the 31 Grid Facts, read the corresponding information from the user's uploaded Excel file.

Each Grid Fact must retain its correct:

* Image Number
* LEVEL Number
* Fact Slot Number
* Fact Title
* Fact Content
* Image Category
* AI Illustration Generator Prompt

Do not generate or substitute unrelated data from the Built-in AI-Generated Database when the uploaded Excel file is the selected source.

---

# 2. Add Category to Every Image Prompt Record

The **“Export Prompts to Excel”** function must be updated.

Currently, the export contains the image-generation prompts related to the 31 facts. From now on, the exported Excel must additionally contain the **category assigned to each fact**.

For every one of the 31 records, export:

| Image Number | LEVEL Number | Fact Slot Number | AI ILLUSTRATION GENERATOR PROMPT | Category |
| ------------ | ------------ | ---------------- | -------------------------------- | -------- |

### Required Fields

**Image Number**
The exact image number from the 31 Grid data.

**LEVEL Number**
The exact level number associated with that fact.

**Fact Slot Number**
The exact fact-slot number associated with that fact.

**AI ILLUSTRATION GENERATOR PROMPT**
The complete image-generation prompt associated with that specific fact.

**Category**
The correctly assigned category from the approved 26-category list below.

Do not omit any of these five fields.

# 4. Category Must Be Determined From the Actual Fact

The category must be assigned by reading and understanding the **complete fact**, not by image number, level, slot number, row order, or a fixed sequence.

The system should determine the **primary educational subject** of the fact and assign the best matching category.

For example:

```text
Axolotl fact
→ Animals

Dinosaur fact
→ Dinosaurs

Planet / galaxy fact
→ Space

Human organ fact
→ Human Body

Ocean animal / marine ecosystem fact
→ Ocean Life

Weather phenomenon
→ Weather
```

If a fact could fit multiple categories, select the category representing the **main subject of the fact**.

# 6. Automatic Category → SVG Icon Mapping

After the category is assigned to each of the 31 Grid Facts:

```text
Fact
 ↓
Determine Category
 ↓
Category Name
 ↓
Find Same-Named SVG Icon
 ↓
Attach Icon to Fact
 ↓
Place Icon Before Title
```

Example:

```text
Fact Category = Animals
        ↓
Find "Animals" SVG
        ↓
Use Animals icon
        ↓
Place immediately before title
```

Another example:

```text
Fact Category = Space
        ↓
Find "Space" SVG
        ↓
Use Space icon
        ↓
Place immediately before title
```

The system must **not randomly select an icon**.

**Category → matching category SVG → icon immediately before title**

# 9. Export and Icon Data Must Stay Synchronized

The category written into **Export Prompts to Excel** must be the same category used to select the SVG icon.

For example:

```text id="a3x9p1"
Excel Export:
Category = Animals

        ↓

Bulk SVG Icon Mapping:
Animals.svg

        ↓

31 Grid:
Animals.svg + Fact Title
```

There must be **one consistent source of truth** for the category.

Do not allow the Excel export to show one category while the Grid uses an unrelated icon category.
