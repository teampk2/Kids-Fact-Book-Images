## DETAILED FEATURE REQUEST

### Feature: Remove Inner White Parts / Elements in Single Preset Renderer

**Location:**  
"Single Preset Renderer" section of the website.

**Current Behavior:**  
When a user uploads an SVG file and enables the **"Remove Background"** option, the system successfully removes the outer background of the SVG. However, it does **not** remove the white parts or white elements located **inside** the SVG file (e.g., inner white shapes, white-filled paths, white decorative elements, or white regions inside the design).

**Problem:**  
As shown in the attached screenshot, an SVG can contain:
- **Outer background** (white or transparent)
- **Inner white parts** (white shapes/elements inside the artwork)

The current "Remove Background" option only handles the outer background, leaving all inner white elements untouched. This results in unwanted white patches remaining visible inside the rendered output.

**Requested Solution:**  
While keeping the existing "Remove Background" function fully intact, Add a **new separate option** directly below the existing "Remove Background" option, while **keeping the existing "Remove Background" function fully intact and unchanged**.

**New Option Name (Suggested):**  
- "Remove Inner White Parts"  
- or "Remove White Elements"  
- or "Remove White Parts Inside SVG"

**New Option Behavior:**  
When enabled, this option must:
- Detect and remove **all white parts and white elements** located inside the uploaded SVG file.
- Apply to anything colored white (`#FFFFFF`) within the SVG, including fills, strokes, shapes, paths, and groups.
- Work independently or in combination with the existing "Remove Background" option.
- Preserve all non-white elements, colors, and design integrity.

**Reference:**  
See attached screenshot — showing:
- **Background White** (outer area)
- **Inner White Part** (white shapes inside the SVG that currently remain)

---

## SHORT SUMMARY

```
Add a new option below "Remove Background" in the Single Preset Renderer that removes all white parts and white elements inside the uploaded SVG file, while keeping the existing "Remove Background" function fully intact. Currently, inner white elements remain even after background removal. See attached screenshot for reference.
```
