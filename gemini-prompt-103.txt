1). **Theme-Based Heading Colors**

Currently, all headings throughout the book use the same color. Update the logic so that **all heading text automatically uses colors that match the overall theme of the book** instead of a single default color.

### Requirements

* Apply a consistent, theme-based color palette to all headings.
* Automatically select attractive, high-contrast colors that complement the book's theme and design.
* Maintain visual consistency across every page and section.
* Ensure all heading colors remain easy to read on both screen and in print.
* Preserve the existing font, size, alignment, spacing, and layout—only change the heading color.
* Apply the theme colors uniformly to all current books and automatically to all future books.
