## Fix Font Embedding in KDP Cover Creator

When a cover is created in the **KDP Cover Creator** section and uploaded to Amazon KDP, the site shows an error that the **fonts are not embedded**.

### Required Fix

Write the code so that **every font used in the Cover Creator** is fully embedded inside the exported PDF.

### Requirements

* Embed all selected fonts automatically during PDF generation.
* Do not allow any font to be exported without embedding.
* Preserve the exact font style, weight, size, and appearance shown in the preview.
* Ensure the PDF remains fully compatible with KDP upload requirements.
* Prevent this font-embedding error from happening again in the future.
* If any font cannot be embedded, block export or replace it with a supported embeddable font before generating the PDF.

### Validation

Before export, verify that:

* ✅ Every font in the cover is embedded.
* ✅ The exported PDF matches the preview.
* ✅ No KDP font-not-embedded warning occurs.
* ✅ The fix works for all current and future Cover Creator fonts.
