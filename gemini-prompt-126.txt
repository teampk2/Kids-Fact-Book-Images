## Fact Box Color Assignment Logic (Apply to All 1,000 Fact Boxes)

### Problem to Fix

I have pointed out this issue multiple times, but it still occurs.

In the attached reference images, the Fact Boxes marked with arrows show that **adjacent Fact Boxes on the same page are using the same background color**. This should **never happen**.

The color assignment logic must be redesigned so this issue is completely eliminated throughout the entire book.

---

## Required Implementation

Apply the following color assignment logic to **every Fact Box page** in the book (all 1,000 Fact Boxes).

### Unique Color Rule

* Every Fact Box on the **same page** must have a **different background color**.
* **No two Fact Boxes on the same page may share the same background color.**
* If a color is assigned to one Fact Box, that color must be **removed from the available color list for the remainder of that page**.
* A previously used color may become available again **only after moving to the next page**.
* This rule must be enforced automatically for every page in the book.

---

## Random Color Selection Logic

The color assignment must be completely randomized.

Requirements:

* Randomly shuffle the available color palette at the beginning of each page.
* Assign colors one by one without repetition.
* Generate a **new random color order for every page**.
* Never reuse the same color sequence across multiple pages.
* Never generate predictable color patterns.
* Every page should have its own unique color arrangement.

---

## Duplicate Color Prevention

Before assigning a color to a Fact Box, validate the following:

* The selected color has **not already been used on the current page**.
* If it has already been used, automatically select another unused color.
* Continue checking until a unique color is found.
* Only after all Fact Boxes on the page have unique colors should the page be considered complete.

This validation must run automatically on every Fact Box page.

---

## Color Palette Requirements

Use only **solid colors**.

Requirements:

* No gradients.
* No color blends.
* No textures.
* No patterns.
* No white or near-white background colors.
* No overly dark colors.
* No overly bright or highly saturated colors.

Use only **light and medium-tone solid colors** that are:

* Soft and comfortable to read
* Child-friendly
* Visually balanced
* Professional
* Print-ready for Amazon KDP

---

## Text Readability

Readability must always take priority.

For every Fact Box:

* Automatically calculate the background brightness.
* Choose the text color that provides the highest contrast.
* Ensure titles, facts, icons, labels, and all text remain clear and easy to read.
* Never allow text to blend into the background.
* Maintain crisp, sharp, print-quality text.

---

## Validation Logic

Before rendering each page, perform the following validation:

* ✅ Every Fact Box has a unique background color.
* ✅ No duplicate colors exist anywhere on the page.
* ✅ Adjacent Fact Boxes never share the same background color.
* ✅ The color order is different from previous pages.
* ✅ All colors come from the approved solid-color palette.
* ✅ Text contrast meets readability requirements.
* ✅ The page passes validation before being exported.

If any duplicate color is detected on a page, automatically regenerate the page's color assignments until **every Fact Box has a unique color**.

---

## Expected Result

Every page in the book should have a **completely unique and randomized color arrangement**, where **every Fact Box has its own solid background color**. No two Fact Boxes on the same page—including adjacent Fact Boxes—should ever use the same color. The color selection should be automatic, visually balanced, easy to read, and consistent across all **1,000 Fact Boxes**, producing a clean, professional, and Amazon KDP-ready design.
