The color assignment logic must be redesigned so this issue is completely eliminated throughout the entire book.

## Required Implementation

Apply the following color assignment logic to **every Fact Box page** in the book (all 1,000 Fact Boxes).

### Unique Color Rule

* Every Fact Box on the **same page** must have a **different background color**.
* **No two Fact Boxes on the same page may share the same background color.**
* If a color is assigned to one Fact Box, that color must be **removed from the available color list for the remainder of that page**.
* A previously used color may become available again **only after moving to the next page**.
* This rule must be enforced automatically for every page in the book.

## Random Color Selection Logic

The color assignment must be completely randomized.

Requirements:

* Randomly shuffle the available color palette at the beginning of each page.
* Assign colors one by one without repetition.
* Generate a **new random color order for every page**.
* Never reuse the same color sequence across multiple pages.
* Never generate predictable color patterns.
* Every page should have its own unique color arrangement.

## Duplicate Color Prevention

Before assigning a color to a Fact Box, validate the following:

* The selected color has **not already been used on the current page**.
* If it has already been used, automatically select another unused color.
* Continue checking until a unique color is found.
* Only after all Fact Boxes on the page have unique colors should the page be considered complete.

This validation must run automatically on every Fact Box page.
