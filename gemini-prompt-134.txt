## MEGA Cloud Sync Hub – Fix PDF Deletion

In the **MEGA Cloud Sync Hub** section of the Facts Book web app, fix the PDF deletion functionality.

### Current Problem

The app successfully syncs and saves the generated PDF to the connected **MEGA.nz** account, but when the user tries to remove a previously synced/saved PDF from the MEGA Cloud Sync Hub, **the PDF is not actually being deleted**.

The screenshot shows the synced PDF entry with the **trash/delete icon** on the right side. The delete action must be fully functional.

### Required Implementation

When the user clicks the **Delete/Trash** icon for a previously synced PDF:

1. Identify the exact PDF file associated with that library/sync record.
2. Connect to the currently authenticated MEGA.nz session.
3. Locate the corresponding file in the user's MEGA storage.
4. Delete the actual file from MEGA.nz.
5. Wait for and verify the MEGA deletion operation succeeds.
6. Only after successful deletion, remove/update the corresponding local sync record in the Facts Book web app.
7. Refresh the MEGA Cloud Sync Hub list so the deleted PDF no longer appears as a synced file.

### Important

Do **not** simply remove the PDF entry from the web app's UI or local database while leaving the actual file on MEGA.

The delete operation must remove the **actual previously synced PDF from the MEGA account**.

### Error Handling

If deletion fails:

* Do not falsely show the file as deleted.
* Keep the sync record visible.
* Display the actual deletion error clearly.
* Handle cases where the MEGA file has already been deleted or moved.
* Handle expired/invalid MEGA sessions appropriately.
* Prevent duplicate delete requests while deletion is in progress.

### Expected Result

The **Delete/Trash** button in the MEGA Cloud Sync Hub should perform a complete deletion:

**Facts Book Web App → Identify synced PDF → Locate PDF on MEGA.nz → Delete PDF from MEGA → Confirm successful deletion → Remove/update local sync record → Refresh the list.**

After successful deletion, the previously synced PDF should **no longer exist in the connected MEGA account and should no longer appear in the MEGA Cloud Sync Hub**.
